# 行迹 Agent · Obsidian 运行全景

提供纸面工程全景与真正的 WebGL 立体微粒视图。界面全中文，可公转、拖动旋转、缩放，提供边界刻度、拖影和光效。

右侧每个移动短杠对应当前方案的一个真实输出字段：

- **悬停**：显示方案、阶段、字段路径和实际值；悬停期间暂停谱线运动，方便阅读。
- **点击**：高亮对应短杠，在详情中查看实际值及来源。点击「查看完整记录」查看整个阶段的输入与输出。
- **输出目录**：搜索阶段、字段或值，点击一项定位对应谱线并打开详情。
- **旋转/缩放后仍可点击**：命中位置直接来自本帧绘制的线段；短杠优先于交叉谱线。
- **退出详情**：关闭面板继续公转；Esc 清除高亮，方向键旋转，双击画布复位。

输出目录与右侧谱线一一对应；切换方案、范围或搜索会同时更新。业务全景每阶段最多展示 100 个字段、总计最多 650 个字段；界面显示实际条数。深层对象以对象值显示，完整阶段记录仍可展开。流程主干模式按阶段汇总。

## 安装

`plugin/` 已包含可直接安装的构建产物，不需要在线加载脚本。

```powershell
node integrations/obsidian/install.cjs "你的 Obsidian 仓库路径"
```

安装脚本只更新本插件代码，备份旧文件，保留运行历史与设置；已有笔记不会被覆盖。在 Obsidian 的第三方插件中启用「行迹 · 工作流星图」，通过命令面板打开工作流视图。若插件已打开，重新加载插件或重启 Obsidian。

也可以手动将 `plugin/` 内文件复制到仓库 `.obsidian/plugins/wayfarer-workflow-atlas/`，再复制 `assets/notes/` 到 `行迹工作流/`。

## 从源码构建与验证

在本项目根目录安装原有依赖后执行：

```powershell
npm install
node integrations/obsidian/build.cjs
node --test integrations/obsidian/tests/*.test.cjs
```

亦可在此目录执行 `npm install`、`npm run build`、`npm test`。构建工具 esbuild 从当前目录或项目根目录解析；运行时复用本仓库 `src/`，不能将此集成目录独立于项目源码构建。

`src/` 为插件源码，`runtime/` 为实际 Agent 入口与阶段载荷插桩，`assets/` 为样式、36 个流程/规则节点与笔记。插桩校验上游入口，源码变化会明确报错，避免静默丢失输出。

## 数据来源

运行按钮实际执行本仓库的本地行程规划器，比较三种节奏方案，采集七个阶段的真实输入、输出、规则结论及实测耗时。目的地缺失时提示补充，异常和不可修复规则保留在记录中。

景点池来自项目内置数据，默认不注入模拟天气；未接入大模型、云端 Agent、真实 Token 或费用计费。该视图没有伪造这些指标。运行历史 `last-business-run.json` 与设置 `data.json` 仅保存在本地，未包含在仓库中。
