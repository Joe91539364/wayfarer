# 行迹智能体业务运行图使用说明

当前星图以业务数据为中心：源码模块、函数与类型定义已从可视粒子中移除。底层旅行规划代码和原笔记仍保留，工作台直接读取本地运行结果。

## 微粒表示什么

- 青色：输入，包括用户原话、目的地、日期、人数、预算及各步骤的入参。
- 绿色：输出，包括地点候选、分日计划、每条实际行程和规则结果。
- 橙色：异常检查入口。待运行或未触发的入口不表示已有故障；真正触发后显示具体原因。
- 紫色：候选方案。每个方案独立执行编排、校验和有界修复。

工作流包含28个步骤和8类校验规则，初始业务图有138个节点。运行产生的候选地点、每日行程和问题清单会继续成为微粒，因此节点数随本轮数据变化。

## 运行与比较

1. 在顶部输入旅行需求，点击“运行并比较方案”。
2. 方案一保持原始节奏；方案二和方案三选择其余节奏，通常形成轻松、均衡、紧凑三个选择。目的地、日期、人数和预算保持原条件。行动受限时不强行提高节奏；相同的最终行程会明确标注。
3. 每个方案都真实执行需求解析、候选检索、分天分区、时间编排、规则校验、修复和结果输出，共七阶段。三方案合计21条阶段记录。
4. 点击方案卡可切换实际行程、微粒和问题；点击下方“真实运行输入输出”记录，或点击图中的微粒，在详情中展开完整值。
5. 方案卡显示实际计算的估算费用、游览活动数量、通勤分钟、错误、提醒与修复轮数。优先查看顺序依据错误数、提醒数，再保留原始偏好顺序。

费用为本地数据与算法估算，不含往返大交通。该工作台不查询实时天气、房态、路况和票价，数据假设会随结果保留。

## 异常示例

顶部下拉菜单可选择示例，点击“填入示例”后再运行。示例会明确改变输入框中的文字。

| 场景 | 运行行为 |
| --- | --- |
| 缺少目的地 | 停止生成，提示补充有效目的地。 |
| 本地资料不可用 | 显示资料缺口，不用其他城市替代。 |
| 零或负数输入、无效日期 | 输入检查阻断，修改后可立即重试。 |
| 预算过低 | 实际计算三方案，保留预算校验及修复后仍存在的问题。 |
| 输出结构不完整、校验未通过 | 标记输出异常；有阻断错误的方案不显示为已通过。 |

“错误”表示阻断问题，“提醒”表示需要留意的条件。首次校验记录和最终方案结果可能因修复而不同，查看阶段详情可追踪变化。下方旧播放控件仅演示结构路径，明确标注为模拟，与真实输入输出记录分开。

## 三维操作

- 默认自动公转，顶部可暂停或调速。
- 鼠标拖拽自由旋转；滚轮缩放；上档键加拖拽或中键拖拽平移。
- 双击图面或顶部“复位”恢复视角。
- 外围角度刻度固定，节点和连线在三维空间内旋转。

本轮输入、候选方案、阶段记录和问题保存在当前知识库本地，重新打开工作台后恢复上次结果。

## 拖影与光效

- 顶部“拖影已开”可独立开关粒子公转轨迹和连线光点的尾光。轨迹约1秒淡出，保留三维深度。
- 光晕菜单提供“光晕关闭”“柔和光晕”“明亮光晕”。粒子保持微小，选中与处理中的节点会突出显示。
- 公转停止后旧轨迹自然消散；暂停动效、复位、缩放或切换筛选会清除不适用的历史轨迹。
- 输入输出文字和角度刻度单独绘制，文字不会产生拖影。
- 拖影开关与光晕强度会保存，重新打开后继续使用。
